How to get the Sheet link
  1. Holdings tab, row 1: Ticker, Name, Units, Avg cost, Price, Prev close
  2. Price: =GOOGLEFINANCE(A2,"price")
  3. Prev close: =GOOGLEFINANCE(A2,"closeyest")
  4. File → Share → Publish to web → Holdings → Comma-separated values (.csv) → Publish
  5. Copy the link and paste it above

Prices are delayed up to about 20 minutes. Add or sell holdings by editing the Sheet; the app picks it up on the next refresh.
